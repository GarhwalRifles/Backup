ehydromet Backup Tool

Private / Personal Use

This application is a private, personal backup utility. It automatically uploads SQL database backups from a personal server to a personal Google Drive folder.

Purpose

The sole purpose of this application is to let the developer's own automated scripts store periodic backups in the developer's own Google Drive account. It is not offered as a service to the public, and no third-party users can sign in or use it.

What it does

  • Authenticates with Google using OAuth 2.0.
  • Uploads database backup files to a private Drive folder.
  • Runs on a schedule (daily/weekly) via the developer's own server.

Data Access

This app only accesses files it creates. It does not read, modify, or share any other data in the user's Google account. See our Privacy Policy for details.
